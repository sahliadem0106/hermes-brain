# Saudi Arabia Cloud Ecosystem Reference

## Overview
Research findings about cloud platform preferences in Saudi Arabia, relevant for users targeting Saudi institutions (KAUST, SDAIA, SDIA, Vision 2030).

## Key Findings

### Microsoft Azure — Strongest Government Position
- **3 Azure Availability Zones** completed in Saudi Arabia (~2025-2026), enabling sovereign cloud workloads
- **SDAIA partnership**: Saudi Data & AI Authority partnered with Microsoft to host **ALLaM** (the national Arabic LLM) on Azure
- **Sovereign cloud**: Microsoft's Saudi region provides "sovereign cloud" capabilities for government entities
- Timelines: Customers could run cloud workloads from Saudi Arabia East datacenter region from Q4 2026

### AWS — Strong Training and Global Dominance
- **Free Saudi AI cloud training program**: Launched for 20,000 professionals in AI, ML, and cloud computing (6-month online program)
- **Regional presence**: AWS serves Saudi Arabia from its Bahrain region
- **Global research standard**: AWS is the dominant cloud for academic ML research worldwide

### Saudi Government Cloud: "Deem" (ضيم)
- Saudi Arabia's government cloud platform
- Built on multiple providers; exact composition varies

### Context for Decision Making

| Factor | Azure | AWS |
|--------|-------|-----|
| Government relations | Strongest (sovereign + ALLaM) | Training programs |
| Research dominance | Growing | Global standard |
| Regional DC | In-country (3 zones) | Bahrain region |
| Applicable cert | DP-100 / AI-102 | AWS ML Specialty |

### Recommendation Rules

For a user targeting:
- **KAUST / Academic research** → AWS ML Specialty (global research standard)
- **Saudi government / SDAIA / Ministry role** → Azure DP-100 (government ecosystem alignment)
- **Both** → AWS ML Specialty (the global research standard is more portable; mention Azure DP-100 only if explicitly asked)
