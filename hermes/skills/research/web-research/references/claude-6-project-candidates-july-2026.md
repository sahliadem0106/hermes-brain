# Claude's 6 Project Candidates — July 2026

Generated by Claude in response to a prompt asking for projects at PP3 difficulty level (🟡 4-6/10), one new skill each, building on existing skills.

## PPA Candidates (extending PP1's CNN/CXR line)

### PPA-1: Domain Adaptation for Cross-Population Models
- **What:** Take PP1 model as frozen starting point. Build ladder of adaptation methods: batch-norm recalibration (no gradients), TENT (entropy minimization), DANN (domain-adversarial).
- **New skill:** Domain adaptation / test-time adaptation
- **Builds on:** PP1 models + datasets + eval pipeline (~70% reuse)
- **Difficulty:** 🟡 5.5/10
- **Time:** 2 weeks
- **Why achievable:** BN recal = ~10 lines. TENT = entropy loss. DANN = optional stretch. PP1 infra exists.

### PPA-2: Beyond the Heatmap — Shortcut Detection
- **What:** Turn Grad-CAM into quantitative audit. NIH ChestX-ray14 has 880 images with 984 bounding boxes across 8 diseases — convert Grad-CAM maps into IoU scores. Then test models for shortcut learning: can they detect hospital system from X-rays? (Zech et al. 2018 showed this is a real failure mode.)
- **New skill:** Interpretability evaluation + shortcut detection
- **Builds on:** Grad-CAM from PP1, eval pipeline, cross-population models
- **Difficulty:** 🟡 6/10
- **Time:** 2-3 weeks
- **Why achievable:** Already generate Grad-CAM. Bounding boxes are pre-labeled. Shortcut detection is statistical/observational.

### PPA-3: Federated Learning Across Simulated Hospitals
- **What:** Treat NIH, Montgomery, Shenzhen, PadChest as 4 hospitals that train locally. Implement FedAvg: each round broadcast global model, each site trains locally, weights averaged. Compare centralized vs isolated vs federated.
- **New skill:** Federated learning
- **Builds on:** PP1 4-dataset pipeline, training loops
- **Difficulty:** 🟡 5/10 on paper, ⚠️ 7/10 in practice (non-IID convergence hard to debug)
- **Time:** 2 weeks optimistic, 4 realistic
- **Risk:** Datasets extremely imbalanced (NIH=112k vs Montgomery=138). FedAvg convergence issues on non-IID data.

## PPB Candidates (extending PP3's few-shot BiomedCLIP line)

### PPB-1: Distillation — Few-Shot Expert → Fast Deployable Model
- **What:** Use best few-shot BiomedCLIP config as teacher, distill into DenseNet/EfficientNet student. Compare hard-labels-only, distilled student, and original teacher across K-shot/disease/seed grid.
- **New skill:** Knowledge distillation
- **Builds on:** PP1 CNNs (student) + PP3 few-shot models (teacher). Both already exist.
- **Difficulty:** 🟡 6/10
- **Time:** 2-3 weeks
- **Why achievable:** Distillation ~15 lines. Both halves already built. Running grid = practiced skill.

### PPB-2: Uncertainty for Few-Shot — MC-Dropout + Ensembles + Conformal
- **What:** MC-Dropout (keep dropout at inference, 20-30 passes, spread = uncertainty). Ensembles (5 seeds from PP3 already are one). Conformal prediction (MAPIE library for distribution-free coverage guarantees). Test: uncertainty grows as K shrinks, and "defer to radiologist" policy catches errors.
- **New skill:** Uncertainty quantification + conformal prediction
- **Builds on:** ECE from PP3, existing 5 seeds = free ensemble, K-shot/disease grid
- **Difficulty:** 🟡 5.5/10
- **Time:** ~2 weeks
- **Why achievable:** MC-Dropout = 5 lines. Ensembles already trained. MAPIE handles conformal math.

### PPB-3: Structured Findings Generation
- **What:** LoRA fine-tune HuggingFace VisionEncoderDecoderModel (ViT + GPT2) on disease labels to generate captions. Controlled vocabulary keeps scope tight. Evaluate with BLEU/ROUGE + clinical accuracy check.
- **New skill:** Vision-language sequence generation
- **Builds on:** HuggingFace transformers + PEFT from PP3
- **Difficulty:** 🟡 6.5/10 — most ambitious, at edge of range
- **Time:** 3 weeks tight
- **Risk:** First generation project. Harder to debug than classification.

## Killed / Not Recommended
- PPA-3 (Federated): Looks simpler than it is. Non-IID convergence on tiny datasets is a PhD-level debugging problem.
- PPB-3 (Structured Findings): Cool skill but the clinical value of generating text from existing labels is questionable. 3 weeks is tight for first generation project.

## Top Recommendations
- **PPA-2 (Shortcut Detection):** Highest application weight (8/10). Shows research thinking, not just engineering. The "shortcut learning" angle is genuinely interesting to professors.
- **PPB-2 (Uncertainty/Conformal):** Same weight (8/10). "My model knows when to say 'I'm not sure'" is clinically meaningful. Connects to trustworthy AI narrative.

Best paired as: PP1 → PPA-2 → PP3 → PPB-2 = one continuous story about trust.
